# KYRAN Digital NFC Profile

Simple static business profile page for `KYRAN Digital`, designed for NFC cards and quick mobile access.

## Files

- `index.html` - Main digital business profile page
- `Style.css` - Page styling
- `profile.jpg` - Branded profile image / logo card
- `contact.vcf` - Downloadable contact card
- `README.md` - Project notes

## Features

- Mobile-first business profile page
- Call, email, WhatsApp, and save-contact actions
- Instagram, LinkedIn, YouTube, and GitHub links
- NFC flow section for card users
- Branding based on the KYRAN Digital teal and sand palette

## Publish

Upload these files to any static host such as GitHub Pages, Netlify, or Vercel.

## Note

The location is currently set to `Udaipur, Rajasthan, India` based on the existing reference profile and can be updated easily in:

- `index.html`
- `contact.vcf`
